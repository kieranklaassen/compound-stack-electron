The first version of the template. An app cloned from it holds all of this
already and has nothing to apply. These instructions are for starting a new app
from the template as a whole.

## Instructions

1. Copy the template into a new repository, without its `.git` folder. Keep
   `.template-manifest.yml` as it is: the app is born with each module adopted
   at `0.1.0`.
2. Rename the example app. In `package.json` change `name`, `productName` and
   `appId`. In `shell/app-link.mjs` change `LINK_SCHEME`. In
   `shell/documents.mjs` change `EXTENSION`. Follow "Renaming a clone" in
   `docs/template-manifest.md` for the rest.
3. Run `npm ci`. Behind a proxy that keeps Electron's binary from arriving,
   follow `docs/solutions/electrons-binary-is-not-fetched-behind-a-proxy.md`.
4. Run `npm run dev` and see the window open. To talk to a backend on this
   machine, run `APP_SERVER=http://localhost:3000 npm run dev`.
5. Read `AGENTS.md`, then the doc under `docs/modules/` for each module before
   changing it.
6. To adopt only some modules into an app that already exists, do not copy the
   whole. Follow "Adopt into an existing app" in each module's doc and list only
   those modules in the app's manifest.

## Verify

Run `npm run check`. It passes with no Electron binary and no display.

On Linux with a display server to hand, also run `xvfb-run -a npm run test:e2e`.
